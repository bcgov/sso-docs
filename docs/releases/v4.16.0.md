# CSS v4.16.0
2026-09-02

### New Features 🎉
- Added a feature to replicate role assignments from IDIR to IDIR-MFA. Aligning role assignments is one of the key challenges when migrating users to the more secure IDIR-MFA login experience. This feature helps streamline the migration process and reduces the administrative effort required to maintain consistent access permissions.


### Bug fixes and enhancement 🐛
- Fixed an issue that prevented composite roles from being deleted.


### Miscellaneous 🧩
- Enhanced the messaging around restrictions on onboarding new Basic BCeID integrations, including additional background information and a link to [Service Bulletin 1749, July 30, 2026](https://ociomysc.service-now.com/sp?id=kb_article&sys_id=4221c6932b1a8b9083eaf885d391bfb8&spa=1) with further details.
